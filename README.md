**Título:** Análisis de embudo y retención para MercadoLibre

**¿En qué etapa del proceso de compra abandonan los usuarios?** En este proyecto analicé el comportamiento de los usuarios a lo largo del embudo de ventas para detectar puntos de fuga y facilitar la identificación de oportunidades de mejora.

- **Problema:** Comprender cómo avanzan los usuarios por las distintas etapas del proceso de compra y reconocer dónde se concentra el abandono.
- **Qué hice:** Transformé y consulté tablas de datos mediante SQL, y convertí los resultados en visualizaciones claras para facilitar su interpretación por parte de stakeholders.
- **Resultado o aprendizaje:** La mayor caída porcentual ocurre entre select_item y add_to_cart.
Conversión promedio:
select_item: 76.9%
add_to_cart: 11.0%
    
    Esto indica que el principal cuello de botella está en la intención de compra inicial, antes de que el usuario agregue productos al carrito.             Mejor desempeño en conversión final (purchase):
    Uruguay (4.55%)
    México (2.48%)
    Perú (1.82%)
    
    Peor desempeño:
    Paraguay, Ecuador y Colombia, con 0% de conversión a compra, lo que sugiere fricciones severas (pagos, logística o confianza).
    
    Brasil, a pesar de su volumen, muestra una conversión final muy baja (0.68%), indicando oportunidades importantes de optimización local.
    
    El negocio tiene una buena captación inicial, pero enfrenta desafíos claros en activación temprana, conversión a carrito y retención post-21 días. Atacar estos puntos puede generar mejoras significativas en ingresos y LTV  o **valor de vida del cliente**. Estos hallazgos permiten orientar futuras iniciativas para investigar las causas del abandono y mejorar la experiencia de compra.
    
- **¿Qué demuestra este proyecto?**
    
    Este trabajo muestra mi capacidad para usar SQL en el análisis del comportamiento de usuarios, comunicar resultados con visualizaciones y convertir datos del proceso de compra en hallazgos útiles para la toma de decisiones.
